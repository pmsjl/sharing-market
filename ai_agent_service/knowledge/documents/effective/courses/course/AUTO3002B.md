# 自动控制实践B：教材、软件与器材资料映射

## 教材

- 《控制系统设计》；作者：王广雄、何朕；出版社：清华大学出版社
- 《自动控制元件及线路》；作者：梅晓榕；出版社：科学出版社；版次：第五版
- 《智能控制系统及应用》；作者：丛爽；出版社：中国科学技术大学出版社

## 软件环境

- **MATLAB / Simulink**：HOA专业软件文章将MATLAB / Simulink列为“自动控制实践”可能用到的软件。
  - 许可或费用：收费
  - 学校环境：学校的计算机房安装有被美国制裁前的 MATLAB R2015b
  - 版本：MATLAB 每年会发行 2 个版本，例如 2023 年有 R2023a 和 R2023b
  - 兼容性：如果你在个人电脑上使用较新版本的 MATLAB，可能出现个别 API 和 2015 年不兼容的情况
