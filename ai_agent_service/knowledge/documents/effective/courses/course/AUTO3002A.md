# 自动控制实践A：教材、软件与器材资料映射

## 教材

- 《电机学》；作者：戈宝军, 梁艳萍, 温嘉斌；出版社：中国电力出版社；版次：第三版
- 《电机学》；作者：汤蕴璆；出版社：机械工业出版社；版次：第 5 版
- 《电机与拖动》；作者：孙建忠、刘凤春等；出版社：机械工业出版社；版次：第 4 版
- 《步进电机应用技术》；作者：[日]坂本正文 (王自强译)；出版社：科学出版社；版次：2010年版
- 《电力电子技术》；作者：王兆安等；出版社：机械工业出版社；版次：第 5 版
- 《Fundamental of power electronics》；作者：Erickson；出版社：Springer；版次：3rd ed.
- 《自动控制元件及线路》；作者：梅晓榕；出版社：科学出版社；版次：第五版

## 软件环境

- **MATLAB / Simulink**：HOA专业软件文章将MATLAB / Simulink列为“自动控制实践”可能用到的软件。
  - 许可或费用：收费
  - 学校环境：学校的计算机房安装有被美国制裁前的 MATLAB R2015b
  - 版本：MATLAB 每年会发行 2 个版本，例如 2023 年有 R2023a 和 R2023b
  - 兼容性：如果你在个人电脑上使用较新版本的 MATLAB，可能出现个别 API 和 2015 年不兼容的情况
